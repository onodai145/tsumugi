# clippy を CI に追加する Implementation Plan(Issue #707、PR 1/2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Linux と Android の clippy 警告を 0 にし、固定版の clippy を CI と pre-push で `-D warnings` にする。

**Architecture:** コードの掃除(Task 1・2)を先に済ませ、最後に版の固定・CI ジョブ・フック・ドキュメント(Task 3)を足す。版は `src-tauri/clippy-toolchain` の 1 か所。

**Tech Stack:** Rust 1.100.0 の clippy、GitHub Actions、pre-commit。

**Spec:** `docs/superpowers/specs/2026-11-26-issue-707-clippy-eslint-design.md`

## Global Constraints

- アプリの挙動を変えない。バグと分かったものはこの PR で直さず、ユーザーに報告して Issue にする。
- 全体で無効にする lint を作らない(`Cargo.toml` の `[lints]` は足さない)。
- 生成される `frontend/src/bindings/tauri.gen.ts` に差分を出さない。
- ブランチは `chore/issue-707-clippy`(作成済み)。コミットは件名 1 行 + `Co-Authored-By` トレーラ。`--no-verify` は使わない。コミットが失敗したら再試行せず報告する。
- `rust-version = "1.88"` を超える API を使わない。
- 重いビルドの前に `free -h` でメモリとスワップを確認し、メモリ上限を付ける。`CARGO_TARGET_DIR` を `/tmp` にしない。

```yaml
  # clippy は版を固定して -D warnings にする(Issue #707)。浮動の stable だと、Rust の新版で lint が増えたときに
  # 無関係な PR の CI が落ちる。版は src-tauri/clippy-toolchain(pre-push のフックも読む)。
  clippy:
    needs: changes
    runs-on: ubuntu-24.04 # rust-test と同じ理由で固定(Issue #594)
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v4

      - name: Install system dependencies (Tauri v2 Linux)
        if: needs.changes.outputs.code == 'true'
        run: |
          sudo apt-get update
          sudo apt-get install -y \
            libwebkit2gtk-4.1-dev \
            libjavascriptcoregtk-4.1-dev \
            libsoup-3.0-dev \
            libgtk-3-dev \
            libayatana-appindicator3-dev \
            librsvg2-dev \
            libasound2-dev \
            patchelf \
            cmake

      - name: clippy の版を読む
        if: needs.changes.outputs.code == 'true'
        id: toolchain
        run: echo "version=$(cat src-tauri/clippy-toolchain)" >> "$GITHUB_OUTPUT"

      - uses: dtolnay/rust-toolchain@df2a88e9fe4098bad09cb42c3dec7187f15861fc # master
        if: needs.changes.outputs.code == 'true'
        with:
          toolchain: ${{ steps.toolchain.outputs.version }}
          components: clippy
          targets: aarch64-linux-android

      - uses: Swatinem/rust-cache@42dc69e1aa15d09112580998cf2ef0119e2e91ae # v2
        if: needs.changes.outputs.code == 'true'
        with:
          workspaces: src-tauri

      # tauri::generate_context!() は frontendDist の実在を要求する。clippy にビルド済みのフロントは要らない。
      - name: Create empty frontendDist
        if: needs.changes.outputs.code == 'true'
        run: |
          mkdir -p frontend/dist
          echo '<!doctype html>' > frontend/dist/index.html

      - name: cargo clippy (Linux)
        if: needs.changes.outputs.code == 'true'
        working-directory: src-tauri
        run: cargo "+$(cat clippy-toolchain)" clippy --all-targets -- -D warnings

      - uses: nttld/setup-ndk@ed92fe6cadad69be94a966a7ee3271275e62f779 # v1
        if: needs.changes.outputs.code == 'true'
        id: setup-ndk
        with:
          ndk-version: r27c
          local-cache: true

      # android-build の同名ステップと同じ(setup-ndk が展開するシンボリックリンクがリンク切れになる)。
      - name: Restore Android NDK symlinks
        if: needs.changes.outputs.code == 'true'
        run: |
          directory="${{ steps.setup-ndk.outputs.ndk-path }}/toolchains/llvm/prebuilt/linux-x86_64/bin"
          find "$directory" -type l | while read -r link; do
              current_target=$(readlink "$link")
              new_target="$directory/$(basename "$current_target")"
              ln -sf "$new_target" "$link"
          done

      # Android 専用のコード(cfg)は Linux の clippy では見えない。テストはデスクトップ専用のものがあるので --lib。
      - name: cargo clippy (Android aarch64)
        if: needs.changes.outputs.code == 'true'
        working-directory: src-tauri
        env:
          NDK_HOME: ${{ steps.setup-ndk.outputs.ndk-path }}
          ANDROID_NDK_ROOT: ${{ steps.setup-ndk.outputs.ndk-path }}
          ANDROID_PLATFORM: android-26
        run: |
          bin="$ANDROID_NDK_ROOT/toolchains/llvm/prebuilt/linux-x86_64/bin"
          export PATH="$bin:$PATH"
          export CC_aarch64_linux_android="$bin/aarch64-linux-android26-clang"
          export CXX_aarch64_linux_android="$bin/aarch64-linux-android26-clang++"
          export AR_aarch64_linux_android="$bin/llvm-ar"
          cargo "+$(cat clippy-toolchain)" clippy --lib --target aarch64-linux-android -- -D warnings
```
